# 検証結果

再作成したアプリケーションをローカルCloudflareランタイムとChromiumで検証しました。

| 検証                                          | 結果                                                                                              |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| TypeScript、Prettier                          | 成功                                                                                              |
| バリデーション・音声許可リストの単体テスト6件 | 成功                                                                                              |
| D1/R2/Clerk形式JWT/DOの統合テスト15グループ   | 成功                                                                                              |
| VOICEVOXのstubエンジン連携                    | 認証、許可リスト、指定credit、R2保存、redirect拒否を確認                                          |
| ブラウザテスト8グループ                       | ユーザー別下書き、別ブラウザ復元、競合時の編集保持、2ブラウザ対戦、ゲスト獲得、モバイル横幅を確認 |
| 実WASM推論                                    | 日本語G2Pと公開テスト用ONNXから非無音WAVを生成                                                    |
| 生成音声のR2保存とHTMLAudio再生               | 成功                                                                                              |
| wrangler deploy --dry-run                     | 成功、DO/D1/R2/Assets bindingを確認                                                               |

DOの検証には同時タップの重複獲得防止、非主催者の開始拒否、全札・目標枚数・時間・主催者終了・絶対期限でのデータとalarm削除、終了URLの無効化、終了後のD1データ保持を含みます。時間系テストはテスト専用のentry pointで期限を短縮し、実際のalarm処理を起動しています。テスト用操作は本番Workerには含まれません。

WASMテストの入力は「こんにちは。みんなでかるたをしましょう。」。最終実行では22,050Hz、104,492 bytes、約2.37秒のWAVが生成され、HTMLAudioの再生位置が進むことを確認しました。初期化を含む生成・保存・再生まで約9秒。性能は端末・モデル・ネットワークで異なります。端末Web Speechによる代替合成は禁止し、外部TTS APIを使用していません。

公開テストモデルの取得元は `ayutaz/piper-plus` revision `035fb7aecf096c40e50493ac25b822e89553c7d6`。モデルSHA256は `375694f9a9c24d57ebbccfff7e16b20a3775a926754603f34123744d2e4d9d2a`。テストのG2P対象を日本語のみにするため、対応設定の音素マップを保持し、言語マップを`ja:0`に絞っています。テストモデルとテスト承認情報は本番に含めません。

未検証：実Clerkアプリでの外部ログイン、実VOICEVOXエンジンの出力品質、本番日本語モデルの利用条件・音質、Cloudflare本番デプロイ、大規模負荷。Clerk本番キー・D1 ID・R2バケットの設定が必要です。
