# かるたアイコン素材一式

採用デザイン：黄色い取り札・波線3本の読み札・中央をタップする指。

## 収録内容

PNG・WebP・AVIF・SVGの4形式。それぞれ16 / 24 / 32 / 48 / 64 / 96 / 128 / 180 / 192 / 256 / 384 / 512 / 768 / 1024 / 2048pxの15サイズ。
背景は透過。サイズは正方形キャンバスの寸法で、周囲に余白があります。

- `svg/karuta-icon.svg`：拡縮用のベクターマスター。画像埋め込みではなくパスで構成。
- `png/`：汎用・透過PNG。
- `webp/`：可逆圧縮・透過WebP。
- `avif/`：高品質設定・透過AVIF。
- `source/approved-design.png`：承認された生成画像の原本。
- `preview.html`：ブラウザで開くサイズ・形式比較。
- `validation.json`：ファイル寸法とアルファチャンネルの検証記録。

SVGは原本から輪郭をトレースして作成したため、微細な質感・輪郭に差があります。配布用のラスター画像はSVGマスターから統一して生成しています。AVIFは非可逆圧縮のため微細な色差があります。

## 用途の目安

16・32・48px：ファビコン。64〜128px：画面内のロゴ。180px：Apple Touch Icon用の寸法。192・512px：Webアプリ用の寸法。1024・2048px：大きな表示・加工用。

Apple Touch Iconなど背景が必要な用途では、利用先の仕様に合わせて背景色を付けてください。この一式は透過素材です。16・24pxでは細部が潰れるため、札と指のシルエットを中心に表示されます。

アプリへの組み込み・公開反映は含みません。
